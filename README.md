### 🧪 What I work on

- **Monte Carlo dosimetry**: voxel phantoms from CT, dose kernels and S-values, validation against published data
- **Pharmacokinetic modelling**: PBPK models, time-activity curves, time-integrated activity
- **Medical image deep learning**: 3D segmentation and regression with SwinUNETR, uncertainty estimation, deformable image registration
- **Statistics for validation**: frozen test splits, paired bootstrap, Bayesian updating
